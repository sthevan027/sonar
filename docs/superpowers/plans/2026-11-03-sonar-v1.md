# Sonar v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar o Sonar v1: app de bandeja para Windows que roteia a saída e a entrada de áudio por app, lembra as regras, tem perfis com ícone e dispositivos renomeáveis.

**Architecture:** Backend Rust (Tauri 2) em módulos pequenos atrás de traits (`AudioSource`, `RouteBackend`), de modo que regras, perfis e armazenamento são testados sem Windows; só as camadas COM (`audio/*`) dependem do sistema e são verificadas à mão. Frontend React/TypeScript fala com o Rust por comandos e pelo evento `state-changed`; o Rust é a fonte única da verdade.

**Tech Stack:** Tauri 2, Rust (crate `windows` 0.62, `directories`, `serde`), React 19, TypeScript, Vite, Vitest, Bun, `lucide-react`, `@fontsource/*`.

**Spec:** `docs/superpowers/specs/2026-11-02-audio-control-design.md` (lê junto). Mockups vinculantes em `docs/mockups/` (A, A2, C, D, D2, E). Código de referência do roteamento: `spike/src/main.rs`.

## Global Constraints

- Stack: Tauri (Rust + React/TypeScript); gerenciador JS **Bun** (`bun install`, `bun run`); app **separado** do Focus Brew.
- Repositório em `D:\Projetos` (nunca em `C:`). Sem rede e sem telemetria na v1: fontes e ícones **locais** (nada de Google Fonts nem Iconify).
- Windows 11 validado; Windows 10 implementado e **não testado** (variante `Downlevel` quando a build é menor que 21390).
- ID enviado ao Windows: `\\?\SWD#MMDEVAPI#{endpoint-id}#{e6327cad-dcec-4949-ae8a-991e976a79d2}` (saída) ou `...#{2eef81be-33fa-4800-9670-1cd474972c3f}` (entrada); **duas barras iniciais**; 111 caracteres para um endpoint típico. Gravar **os dois papéis** (`eMultimedia`=1 e `eConsole`=0); texto vazio limpa a rota.
- Variantes da interface `AudioPolicyConfig`: build >= 21390 usa IID `ab3d4648-e242-459f-b02f-541c70306324` com 19 slots reservados; abaixo disso, `2a59116d-6c4f-45e0-a74f-707e3fef9258` com 17. `Set` fica no slot `6 + reservados`, `Get` no seguinte.
- Chave da regra: nome do executável em minúsculo + fluxo (saída/entrada); vale para todos os PIDs do exe. UWP/MSIX fora da v1.
- Perfil: item sem saída/entrada = **não mexe**; `"padrão"` = limpa a rota; ativar atualiza as regras lembradas; só ativação manual; sem "desativar".
- Persistência em `directories::ProjectDirs("com","sthevandev","sonar")`: `settings.json`, `devices.json`, `rules.json`, `profiles.json`, todos com `version`, gravação **atômica** (temporário + renomear) com cópia `.bak`.
- Nome de dispositivo/perfil: até 20 caracteres (contador "n / 20" dos mockups); nome do perfil opcional.
- Atalho global padrão `Win+Alt+V`, editável. Painel abre ao **clicar** no ícone da bandeja; fecha ao perder o foco; uma só instância.
- Visual: grafite `#1B1A18`, cartão `#25231F`, linha `#37332B`, texto `#EDE6D6`, mudo `#9A917F`, latão `#D9A441`, azul-acinzentado `#86A9B8`, verde `#8FBF7A`; Bricolage Grotesque (títulos), DM Sans (texto), JetBrains Mono (números); painel 388x668 dentro de uma janela transparente 420x700.
- Fora da v1: equalizador, volume de mic por app, ativação automática de perfil, tela de primeiro uso, instalador assinado.

## Review Focus

1. Arquivo JSON truncado ou inválido na abertura: usa o `.bak`; se também falhar, usa o padrão e guarda o ruim como `.corrupt`; nunca derruba o app (Task 2).
2. O app fecha entre enumerar a sessão e rotear (PID some): erro ignorado, as outras regras continuam (Task 6).
3. Regra aponta para dispositivo ausente, desativado ou oculto: regra preservada sem erro, reaplicada quando o dispositivo volta (Task 6).
4. Build do Windows desconhecida ou chamada COM falhando: roteamento desligado com aviso no painel; volume, perfis e o resto seguem funcionando (Tasks 3 e 9).
5. Nome vazio, só espaços, maior que 20 caracteres ou com caracteres de controle: rejeitado/normalizado; "Restaurar" volta ao nome do Windows (Tasks 9 e 13).
